# Market Atlas

Market Atlas is an AI-powered research assistant for investment analysis.

## What it does

- Accepts a company name as input
- Collects external evidence
- Runs multiple analyst-style evaluations
- Produces a final recommendation

## Tech stack

- Next.js (frontend and API)
- TypeScript
- LangGraph workflow orchestration
- External search for evidence

## Project structure

- `src/app` - UI and API route handlers
- `src/lib` - core logic for research, scoring, and workflows
- `src/types` - shared TypeScript types

## Getting started

1. Install dependencies
2. Run the app locally
3. Use the UI to analyze a company
